# Luces PC

Web-app gratuita para controlar tiras LED Bluetooth baratas (controladores ELK-BLEDOM, MELK, LEDBLE… las que usan las apps LotusLamp X / LotusLanternX).

- Color, brillo, blanco frío/cálido, efectos con velocidad, modo música con el micrófono, temporizador y favoritos.
- Funciona en Chrome/Edge (Android, Windows, Mac) y en iPhone con el navegador Bluefy.
- Se instala como app y abre sin internet.

Protocolo basado en [dave-code-ruiz/elkbledom](https://github.com/dave-code-ruiz/elkbledom) (MIT).
